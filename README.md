# 🍽️ ZanFood Restaurant Landing Page

Welcome to **ZanFood Restaurant Landing Page**, a modern restaurant website built using **HTML5** and **CSS3**. This project features a clean and elegant design that showcases a restaurant's services, menu, customer reviews, reservation form, and contact information.

---

## ✨ Features

- Modern Navigation Bar
- Hero Section
- About Us Section
- Services Section
- Food Menu
- Customer Reviews
- Online Reservation Form
- Contact Information
- Hover Effects and Smooth Transitions
- Font Awesome Icons

---

## 🛠️ Built With

- HTML5
- CSS3
- CSS Flexbox
- Font Awesome

---

## 🚀 How to Run

1. Download or clone this repository.
2. Make sure all project files remain in the same folder.
3. Open **restaurant.html** in your web browser.
